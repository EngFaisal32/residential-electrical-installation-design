## Drawing E-01 — included information

- Residential apartment lighting and socket outlet layout
- Circuit identification **C1–C8**
- **DB-01** distribution board schedule
- Simplified single-line diagram and outgoing protection
- Electrical symbol legend and general notes
- Designer and drawing reference

## Interpretation notes

The final sheet title block states **NTS (not to scale)**. A written report for the project describes a nominal 1:50 floor plan; the repository uses the title-block notation until that discrepancy is resolved.

The source DWG is provided as submitted; this repository has not re-engineered or independently certified the drawing geometry or circuit sizing.
