# Design Scope, Limitations and Further Engineering Work

## Project classification

**Self-directed educational drafting project. Not issued for construction.** The goal was to practice residential electrical layout coordination and production of a basic drawing package in AutoCAD.

## What the supplied drawings demonstrate

- Placement and identification of lighting/switching and power points
- Eight circuit labels assigned to an apartment plan
- Single-phase DB-01 schematic arrangement
- A table of nominal connected loads and associated currents
- Preliminary cable cross-sections and breaker/RCBO references
- A drawing sheet with legend, notes and title block

## What has **not** been demonstrated

1. Demand/diversity-adjusted feeder load assessment.
2. Verified conductor current-carrying capacity for actual installation conditions.
3. Voltage drop and conductor derating calculations.
4. Prospective short-circuit current and protective-device breaking capacity.
5. Earth-fault loop impedance, earthing details and disconnection times.
6. Coordination/selectivity and residual-current device type suitability.
7. Appliance manufacturer's installation and protective-device requirements.
8. Construction site verification, inspection, tests or local code approval.

## Drawing consistency items

- **Scale:** The title block reads **NTS**; the narrative report mentions nominal **1:50**.
- **Protection labels:** The load schedule names both B10/B16/B20 MCBs and 30 mA RCBO protection. The diagram is simplified and is not a substitute for a manufacturer-level wiring/protection schedule.
- **Feeder current:** 7,672 W / 230 V = 33.36 A is the arithmetic connected-load calculation, not a final design-current specification.

## Next improvements for a larger portfolio revision

- Add verified installation method and cable selection calculations.
- Add voltage-drop and fault-level estimates.
- Confirm the final RCBO characteristics and device schedule.
- Include room labels, a consistent scale and a final drawing revision number.
- Produce a short design assumptions sheet.
